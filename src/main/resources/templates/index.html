Online Shop Java Platform

A Java OOP console prototype evolved into a Spring Boot web application with persistence, security, asynchronous order tracking, and a preserved Original CLI Mode.

Explore Products Open Original CLI Mode

Original Foundation

The project began with `User`, `Customer`, abstract `Product`, `Clothing`, `Electronics`, `Order`, and menu-driven checkout behavior.

Modern Backend

Spring Boot, JPA, PostgreSQL, validation, sessions, role-based authorization, DTOs, services, and transactional checkout.

Live Tracking

The old `Order extends Thread` idea is modernized as a Spring-managed asynchronous workflow streamed with SSE.
